# Официальный протокол проверки на истории (организаторы)

Реализация: `src/reco_mvp/evaluation/organizers.py`. Воспроизводит правила листа
«Протокол_проверки» книги организаторов (версия датасета 5 от 26.11.2026):

- обучение: `order_week <= 2026-08-31`; проверка: `order_week >= 2026-09-07` до конца данных;
- корзина — пара `(order_id, order_week)`; угадываются новые для клиента `item_id`;
- ровно 3 товара на клиента; меньше 3 — промах (фиксированный знаменатель 3);
- группа A — клиенты с покупками обучения и ≥1 новым товаром проверки (337 клиентов:
  B2B 302, B2C 35); группа B — подмножество с ровно одним товаром в истории
  (172: B2B 147, B2C 25); метрики отдельно по `client_group`;
- отдельно считается доля попаданий-вариантов (`product_group` угаданного товара
  уже в истории клиента).

## Проверка корректности

Golden-тест `tests/evaluation/test_organizers_protocol.py` воспроизводит
опубликованную таблицу baseline организаторов с точностью до округления
(популярность 5.44/3.75/20.0 и 7.36/5.22/20.0; совместные покупки
5.64/4.53/15.24 с Fill 92.3 и 6.01/4.54/14.67 с Fill 87.2; доли вариантов
10.5/12.2/6.2 и 6.5/10.0/0). Тест требует `data/raw/source.xlsx` (git-ignored)
и пропускается без него.

## Запуск

```sh
python -m app.run_pipeline --workbook data/raw/source.xlsx --official \
  --feed data/raw/Mindbox.yml.gz --output artifacts/demo
```

Пишет `artifacts/demo/official/official_metrics.json` (baseline, эвристика,
LTR) и `ranker.pkl`. Без `--feed` вендорные признаки не используются; без
`--skip-ltr` обучается ранжировщик (требуется extra `ranker`).

## Результаты на официальном периоде (финальная сверка)

Единственный прогон на официальном тестовом периоде; модель и гиперпараметры
зафиксированы до него (см. `docs/model/learned_ranker.md`).

| Метод | Группа A: все / B2B / B2C | Группа B: все / B2B / B2C | Fill Rate A | Доля вариантов (A) |
|---|---|---|---|---|
| baseline «Популярность» | 5.44 / 3.75 / 20.0% | 7.36 / 5.22 / 20.0% | 100% | 0% |
| baseline «Совместные покупки» | 5.64 / 4.53 / 15.24% | 6.01 / 4.54 / 14.67% | 92.3% | 10.5% |
| Эвристика проекта | 12.76 / 11.81 / 20.95% | 13.76 / 12.70 / 20.0% | 100% | 35.7% |
| Обучаемый ранжировщик (LTR) | **14.34 / 13.58 / 20.95%** | **15.50 / 14.51 / 21.33%** | **100%** | 35.9% |

Группы и их размеры взяты из протокола организаторов и совпали точно (337/172).
B2C в проверке мал (35/25 клиентов) — результат шумный, как отмечено самими
организаторами. Метрики — наблюдение на истории, а не измеренный эффект в ЛК;
цен и показов в данных нет.

## Отличия от внутреннего бэктеста

Внутренний протокол (`docs/evaluation/protocol.md`) строже к будущему (физическая
изоляция `fit`, когорта холодного старта, бутстрэп-интервалы) и отличается
определениями: например, Fill Rate там — доля заполненных позиций, а в протоколе
организаторов — доля клиентов хотя бы с одной рекомендацией. Числа двух протоколов
несопоставимы без явного указания выборок и определений.
